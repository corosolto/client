# Invasão dos Javaporcos: artes-conceito do layout novo (30/10/2026)

Alvo visual do Gauntlet. São conceito, não asset de jogo; nada daqui carrega em runtime.
Geradas no mint.gg (projeto "CORO SOLTO — Javaporcos"), 1408×768, reduzidas para 1200 px.

| arquivo | o que fixa |
| --- | --- |
| `conceito-a-aerea.webp` | layout macro: cidade em grade → faixa de pasto com cerca → parede de mata; 3 trilhas de entrada |
| `conceito-b-campo.webp` | a transição na altura do olho: meio-fio, pasto de ~8 m com mourões e cupinzeiro, borda da mata |
| `conceito-c-beco.webp` | beco de 2,5 m entre fundos de casa: reboco descascado, medidor, varal, botijão, lixo revirado |
| `conceito-d-rua.webp` | rua comercial tomada: fachadas com letreiro pintado, poste com fiação, caçamba, Uno/Gol batidos |
| `conceito-e-praca.webp` | praça da igrejinha: feira, ipê, pedra portuguesa, barricada de saco de areia e pneu |

O wallpaper de carregamento do modo saiu da mesma rodada: `public/img/loading-javaporcos.webp`.

Decisões do dono que este layout traduz (30/10/2026): os javaporcos querem DOMINAR o mapa,
então entram por 3 frentes de trilha, e não por todo lado; becos levam para dentro dos quarteirões;
o pasto entre a mata e a cidade dá linha de tiro antes do contato; a partida é perdida com 75% de domínio.
