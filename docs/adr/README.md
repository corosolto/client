# ADRs

Decisões de arquitetura congeladas. Formato curto: contexto, decisão,
consequências. Uma ADR nova substitui a antiga; nenhuma é editada para
dizer outra coisa depois de aceita.

| [0001](0001-zero-build.md) | O cliente do jogo não tem build |
| [0002](0002-duas-zonas.md) | Jogo em `public/`, site em `src/`, fronteira medida |
| [0003](0003-agpl.md) | Licença AGPL-3.0 |
| [0004](0004-regua-mutavel.md) | Quality gate com régua mutável |
| [0005](0005-godot-recusado.md) | Cliente Godot recusado como direção |
| [0006](0006-doc-interna-fora.md) | Documentação interna não vive neste repo |
