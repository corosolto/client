# Limites da captura histórica

Este diretório preserva evidência histórica do fix de tiro na boca do cano em 3P. O BOT
troca de arma entre as gravações (p90 antes, `awp` depois), então **não** é uma comparação
A/B pareada de BOT. O AK em 1P/3P permanece constante, mas ambas as gravações contêm um erro
de import dinâmico do Astro; nenhuma é uma execução limpa do fluxo completo.

Este README apenas qualifica os artefatos existentes (`medidas.json` e os `.jpg`, aqui
intocados); nenhuma reexecução, captura nova, validação de produção ou MP ocorreu. Para as
fontes atuais, validação posterior e seus limites, veja
[continuação visual](../../reports/VISUAL-RELEASE-CONTINUATION-20261031.md). Não promova a
captura antiga como evidência do estado atual.
