# Concepts 2D dos políticos (PR #773)

Gerados em 07/10/2026 por `tools/personagens/gen-concept.mjs` a partir de
`tools/personagens/fichas/<id>.json` (OpenRouter, `google/gemini-3-pro-image`,
duas variações, uma escolhida). O prompt completo sai de
`node tools/personagens/gen-concept.mjs <ficha> --print`.

As fotos de referência das pessoas reais (Wikimedia Commons, CC BY / CC BY-SA /
domínio público, autor e licença anotados fora do repo) serviram só ao concept
e não estão versionadas, como pede o CONTRIBUTING.md. A segunda referência de
todo pedido é `tools/personagens/estilo-elenco.jpg`.

Cada `concept.jpg` é a entrada do Mint para o modelo 3D. A Dama tem
`FONTE.md` e prompt próprios porque foi gerada antes do script.
