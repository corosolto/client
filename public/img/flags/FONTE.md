# Bandeiras dos nós de multiplayer

Derivados WebP 80×54 (sharp, `fit:cover`, q88) dos SVGs oficiais do Wikimedia
Commons. Bandeiras nacionais são símbolos de estado, domínio público:

- `br.webp` — [Flag_of_Brazil.svg](https://commons.wikimedia.org/wiki/File:Flag_of_Brazil.svg), PD.
- `us.webp` — [Flag_of_the_United_States.svg](https://commons.wikimedia.org/wiki/File:Flag_of_the_United_States.svg), PD.
- `es.webp` — [Flag_of_Spain.svg](https://commons.wikimedia.org/wiki/File:Flag_of_Spain.svg), PD.

O mapa região→arquivo mora no `main.js` (`MP_BANDEIRAS`): o nó `eu` (Europa ·
Madri) usa a bandeira da ESPANHA porque é onde a VM vive. Nó novo = SVG novo do
Commons pelo mesmo pipeline + uma linha no mapa.
